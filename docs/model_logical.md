# Логическая модель — «Витрина хоккеистов» (Молодёжка)

## Сущности (9)

| Сущность | Назначение |
|----------|------------|
| User | Учётная запись: логин, роль, ФИО |
| Arena | Ледовая арена |
| Team | Команда (домашняя арена, спонсор) |
| HockeyPlayer | Игрок каталога + **status** + **notes** |
| Achievement | Награда / регалия |
| Contract | Контракт игрока с командой (активный — по сути 1:1) |
| TransferOffer | Оффер спонсора на найм игрока |
| ScoutReport | Отчёт / оценка скаута |
| ShortlistEntry | Элемент шортлиста скаута (M:N скаут↔игрок) |

Связь **Player ↔ Achievement** — M:N через набор `achievementIds` (логически — таблица связи).

## Статус игрока

Обязательное поле `status`:

- `in_roster` — в строю
- `injured` — травмирован
- `suspended` — дисквалифицирован
- `free_agent` — свободный агент

`notes` — необязательный текст пометок (до 2000 символов).

## Типы связей

| Связь | Тип |
|-------|-----|
| HockeyPlayer — Contract (активный) | **1:1** |
| Arena → Team | **1:N** |
| Team → HockeyPlayer | **1:N** |
| Team → Contract / TransferOffer | **1:N** |
| User(sponsor) → Team / TransferOffer | **1:N** |
| User(scout) → ScoutReport / ShortlistEntry | **1:N** |
| HockeyPlayer → ScoutReport / TransferOffer / ShortlistEntry | **1:N** |
| HockeyPlayer ↔ Achievement | **M:N** |
| Scout ↔ HockeyPlayer (через ShortlistEntry) | **M:N** |

## Роли

| Роль | Уникальный раздел | Права кратко |
|------|-------------------|--------------|
| admin | Пользователи, hard-delete/restore, сводка | Полный CRUD |
| sponsor | Офферы, свои команды/контракты | Каталог + найм |
| scout | Отчёты скаута, шортлист | Каталог (чтение) + свои отчёты |

## Матрица прав (операции)

| Операция | scout | sponsor | admin |
|----------|-------|---------|-------|
| Просмотр каталога (игроки/команды/арены/награды) | + | + | + |
| CRUD игроков / команд | − | + | + |
| CRUD арен / наград (справочники) | − | − | + |
| Контракты (просмотр) | + | + | + |
| Контракты / офферы (изменение) | − | + | + |
| Отчёты скаута / шортлист | + (свои) | − | + |
| Пользователи / роли | − | − | + |
| Soft-delete игроков/команд | − | + | + |
| Soft-delete арен/наград | − | − | + |
| Hard-delete / restore | − | − | + |

Клиентская проверка прав — удобство UI. Сервер отклоняет чужие операции кодом **403**.
